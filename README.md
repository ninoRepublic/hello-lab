# 🌍 宝贝的科学乐园

> 一个给 3 岁小朋友做的互动科普网站 —— 用图形动画的方式，让孩子"玩着玩着"就认识了太阳系、白天黑夜、四季变化、月亮圆缺、太阳起落这些科学现象。

---

## 一、设计理念

3 岁儿童的认知特点：

- 注意力持续约 5–10 分钟 → 每个模块短小精悍，1–2 分钟就能"玩完"
- 靠感官学习（看、摸、听） → 动画 + 触摸交互 + 音效
- 不认字 → 尽量不用文字，全靠图形动画演示
- 喜欢重复 → 每个动画循环播放，可以随时点触触发

**视觉风格**：圆润卡通造型、马卡龙色系、大按钮、无棱角、背景星星点缀。

---

## 二、技术栈

| 层级 | 技术 | 理由 |
|------|------|------|
| **框架** | Vue 3 + Vite | 轻量、组件化、热更新极快、开发体验好 |
| **语言** | JavaScript (ESM) | Vue 3 `<script setup>` 语法糖 |
| **动画引擎** | Canvas 2D + `requestAnimationFrame` | 高性能，精细控制每一帧动画 |
| **状态管理** | Vue 3 `reactive` / `ref` | 足够小项目使用，不引入 Pinia |
| **样式** | `<style scoped>` + SCSS（后续可加） | 组件内聚 |
| **音效** | 原生 Web Audio API | 零外部依赖，点击"叮"声、火箭声 |
| **部署** | Vercel / GitHub Pages | 免费，push 后自动上线 |
| **设备** | 主要面向 iPad / 手机触屏 | 3 岁小朋友用 iPad 最方便 |

> **核心选型思路**：Canvas 2D 做天文动画足够用了，比 Three.js 轻很多。如果以后想升级 3D（比如想让整个星系旋转），再引入也不迟。

## 五、已完成模块

### 🪐 太阳系运行图

**演示内容**：太阳在中心，八大行星（加月球绕地球）按真实公转周期比缩放公转。

**交互点**：

| 交互 | 效果 |
|------|------|
| 🖱️ **点击任意行星** | 弹出卡通信息卡片 + 清脆叮声 |
| 🎯 **底部快捷按钮** | 直接选星球看介绍 |
| ⏩ **速度滑块** | 0–5 倍速调节公转快慢 |
| 🚀 **发射火箭** | 点一下火箭带着尾焰飞出屏幕 |
| 🔄 **重置** | 随机打乱行星位置，速度归位 |

**视觉亮点**：

- 🌌 **星空背景**：数百颗星星一次性生成，每颗独立闪烁（不是每帧随机，不卡顿）
- ☀️ **太阳**：三层径向渐变光晕 + 呼吸式脉动
- 💍 **土星环**：两层金色椭圆环带
- 🌙 **月球**：绕地球公转的小灰球 + 高光
- 🪐 **卡通比例**：轨道半径**人为分层**（不按真实 AU 比例），保证八颗行星在同一屏幕都能看清、都能点
- 🎨 **高光效果**：每颗行星右上角有白色高光，看起来圆鼓鼓的像糖果

**技术细节**：

- 行星数据保留真实公转周期 `period`（单位：地球年），用于计算公转速度
- 轨道半径 `orbit` 是**展示用的分层值**，不对应真实距离
- `scale` 根据屏幕宽高自适应：让最外层海王星轨道完整显示在屏幕内
- Canvas DPR 限制为 2（Retina 屏），避免 iPad Pro 上性能浪费
- 构建产物仅 **77 KB**（gzip 30 KB），秒开

## 六、待开发模块规划

### 🌍 模块2：白天黑夜的原理

**演示内容**：地球仪 + 一束平行光代表太阳光，地球自转 → 被照到的一半是白天，另一半是黑夜。

**交互点**：
- 👆 用手指拨动地球 → 地球跟着转，晨昏线跟着动
- 🔦 小手电筒图标，可以拖来拖去模拟阳光方向
- 🌆 白天那半边显示蓝天，夜晚那半边显示星空，晨昏线处有柔和渐变
- 语音同步："你看！我们转到太阳这边就是白天~"

### 🌸 模块3：四季冷热的原理

**演示内容**：地球绕太阳公转（椭圆轨道），同时自转轴倾斜 23.5°，一个小人站在地球北半球。

**交互点**：
- 🔄 点击"开始公转"，地球绕太阳转一圈（一年）
- 👆 手动拖动地球在轨道上移动
- 观察小人穿衣服变化：🔥短袖 ↔ 🍂薄外套 ↔ ❄️大衣 ↔ 🌸春装
- ⏩ 加速按钮，快速体验四季轮回

> 注意：小朋友**只需要看到小人穿衣服的变化和地球位置的关系**，不要讲"地轴倾斜"这种术语。

### 🌙 模块4：月亮的圆缺

**演示内容**：太阳 → 地球 → 月球三者位置关系，月球绕地球转一圈（约一个月）。

**交互点**：
- 🎯 核心交互：三个圆（太阳黄、地球蓝、月亮灰），小朋友**拖动月亮绕地球转**
- 🌑→🌓→🌕→🌗→🌑 月相实时跟随位置变化
- "大脸"按钮：显示地球人视角看到的夜空中的月亮

### ☀️ 模块5：太阳升起和下落

**演示内容**：一个小人站在山坡上，太阳沿着弧形轨道从左边升起 → 头顶 → 右边落下。

**交互点**：
- 👆 **拖动太阳**沿弧形轨道移动
- 背景实时变化：🌅朝霞 → ☀️蓝天最亮 → 🌇晚霞 → 🌙夜晚
- 小人的影子**实时跟随**太阳方向和高度变化
- 不同时段有不同环境音效（鸟鸣、风声、虫鸣）

## 九、面向儿童的科普原则

1. **做给小朋友看的，不做给大人看的** —— 不需要精确到小数点后几位的真实物理数据，需要的是**让孩子一看就懂、一摸就会**的视觉模型
2. **让孩子亲手做，不是让孩子看** —— 拨动地球、拖动月亮、发射火箭，动手 > 看动画
3. **科学原理藏在互动里** —— "月亮不是变形状了，是太阳照到它的角度变了"这个道理，小朋友拖两下月亮自己就能悟到
4. **尽量少用文字** —— 用 emoji、颜色、声音、动画代替
